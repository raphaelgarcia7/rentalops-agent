# Registros de decisão

Use esta pasta para decisões arquiteturais importantes, especialmente quando existem duas ou mais opções razoáveis de AI Engineering.

## Formato sugerido

Crie um arquivo numerado, por exemplo `0001-conversation-checkpoint.md`, com:

1. **Contexto:** qual necessidade real motivou a decisão.
2. **Opções:** alternativas viáveis e suas consequências.
3. **Recomendação:** opção escolhida e por quê.
4. **Trade-offs:** custo, complexidade e limitações aceitas.
5. **Falhas:** o que o usuário e o sistema observam quando a solução falha.
6. **Revisão:** quais evidências podem justificar reabrir a decisão.

Decisões mecânicas de implementação não precisam de um registro formal.
